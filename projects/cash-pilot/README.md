# Cash Pilot

A cross-platform personal finance and expense tracking application.

## Overview

Cash Pilot brings income and expense tracking, financial analytics, and reactive state management into a mobile experience.

## Tech Stack

- Flutter and Dart for the mobile application
- Provider for state management
- FL Chart for interactive financial analytics

## Features

- Income and expense tracking
- Financial summaries and interactive charts
- Reactive updates across the application
